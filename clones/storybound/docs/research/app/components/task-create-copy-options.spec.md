# TaskCreateForm 文案选项分层规格

## 证据来源

- Storybound v1.16.1 已解包运行资源：
  - `assets/index-27bFauVN.js`：改写强度、叙事视角、带货模式组件。
  - `assets/index-jF7neVyo.js`：固定开头、锁定原文开头、尾部引导库、处理模式联动和流水线拼接逻辑。
- 用户提供的原版教程画面：尾部引导列表具备单选、编辑、删除和新增操作。
- 本规格只复刻公开可观察的交互、默认文案和本地处理逻辑，不复刻账号、积分或授权后台。

## 层级和显示规则

1. 执行模式始终显示：
   - `auto` 全自动：AI 改写并智能分句。
   - `semi_auto` 半自动：不改写，AI 智能分句。
   - `direct` 直接出片：不改写，按空行和标点机械切分。
2. 暂停策略始终显示；自定义模式展开步骤复选项。
3. 仅 `auto` 展开：
   - 改写强度。
   - 叙事视角。
   - 带货模式。
   - 目标字数。
4. 非 `auto` 显示“无改写过程”的解释，不显示改写强度、叙事视角和带货模式。
5. 旁白视频显示固定开头和尾部引导；双人播客隐藏这两个单人旁白专用配置。
6. 非 `direct` 显示目标分镜数。

## 改写强度

严格使用原版三个值和文案：

| value | 名称 | 说明 |
| --- | --- | --- |
| `standard` | 标准改写（推荐） | 贴近对标结构，延续爆款概率高 |
| `deep` | 深度改写 | 大幅变换表达和细节，原创度显著提升 |
| `rewrite` | 高度原创 | 仅保留核心故事线，结构行文几乎全新 |

旧任务中的 `light` 在加载时迁移为 `standard`。

## 叙事视角

| value | 名称 | 说明 |
| --- | --- | --- |
| `original` | 保持原文（默认） | 不改变叙事人称，保留原稿视角 |
| `first` | 第一人称 | 以主角「我」的视角讲述，代入感强 |
| `third` | 第三人称 | 旁白视角客观叙述，适合故事类 |

## 带货模式

- 关闭：改写时删除带货段落。
- 开启：保留产品推荐和促单内容。
- 该值必须进入 WriterAgent 上下文，不能只改变 UI。

## 固定开头

- 总开关关闭时，不向流水线传固定开头或锁定句数。
- 开启后提供两个模式：
  - `account` 账号开场白：用户输入一段每次任务复用的固定开场白，原样拼在正文最前，AI 正文不得重复。
  - `lock` 锁定原文开头：锁定前 1–20 句。根据当前输入文案自动回填预览，用户可手动修改；修改后以编辑内容为准。
- `account` 模式传 `fixedIntro`，`lock` 模式传 `fixedIntro`（手动编辑文本）和 `lockIntroSentences`。

## 尾部引导

- 总开关关闭时，不向流水线传 CTA。
- 开启后显示本地引导库，默认包含原版五条：
  1. 关注我，下一期我们接着聊这样的故事。
  2. 点个关注，下回咱们接着聊那些不能忘的故事。
  3. 关注我们，我们会继续讲述这些不该被遗忘的故事，一起守护这段珍贵的记忆。
  4. 如果{主角}的故事打动了你，请点亮小红心，在评论区写下致敬{主角}，让更多人记住他，你的每次点赞和分享都是对{主角}最好的纪念。
  5. 如果你的手机还有哪怕百分之一的电量，请为{主角}点上一朵电子鲜花，让更多人看到他的名字。
- 每条支持单选、编辑和删除；列表末尾支持新增。
- 引导库写入 `localStorage`，刷新页面后保留。
- 编辑当前选中项时同步更新任务 CTA；删除当前选中项时清空选择。
- `{主角}` 作为运行时占位符保留给正文元数据替换逻辑。

## 流水线行为

- `PipelineContext` 必须携带 `keepPromotion`、`fixedIntro`、`lockIntroSentences` 和 `outroCta`。
- WriterAgent 的任务上下文必须能看到以上配置。
- 改写完成后由服务端做一次确定性首尾拼接：
  - 已存在的固定开头或 CTA 不重复追加。
  - 固定开头、正文、CTA 之间使用两个换行。
- 半自动和直接出片仍按原版执行模式跳过改写；首尾配置在后续任务上下文中保留。

## 验收

- 切换三种执行模式，显示层级与上述规则一致。
- 三档改写、三档叙事视角、带货开关可选且保存到任务。
- 固定开头两种模式可切换；锁定句数限制为 1–20。
- 引导文案可以新增、编辑、删除、选择；刷新后仍存在。
- 构建、类型检查和 lint 通过。
- 在本地浏览器中创建或打开草稿，刷新后任务选项仍被恢复。
