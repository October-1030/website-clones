# 独立复刻范围与当前实现

## 1. 已完整独立实现

- 桌面导航、创作表单、任务详情、队列、历史、模板、市场和实验室 UI。
- 图文 7 步状态机，以及全自动、半自动、直接出片三种起点。
- 暂停确认、编辑中间产物、断点续跑、局部修复、从指定步骤重跑。
- 每任务独立 JSON 目录、事件日志、批次执行、刷新恢复和任务直达 URL。
- 用户自带 LLM、MiniMax / OpenAI-compatible 图片、MiniMax / 火山 TTS 适配层。
- 可选命令行 ASR 适配、FFmpeg 音频处理、字幕生成与时间轴对齐。
- Chromium HTML/CSS 场景逐帧渲染、FFmpeg H.264/AAC MP4 合成和回退渲染器。
- 人物素材库、提示词模板、草稿模板、画图实验室、配音实验室和本地创作市场。
- 图片、音频、字幕、标题、封面和 BGM 分轨的剪映草稿目录与 ZIP。

## 2. 原站私有服务的独立替代

| 原功能 | 当前独立实现 |
| --- | --- |
| Storybound 激活、配额、积分和订阅 | 明确标注的本地模式；不伪造原站账户或余额 |
| “全能绘图”、即梦等私有计费接口 | MiniMax `image-01` 与用户自有 OpenAI-compatible 图片接口 |
| 创作市场远端后台 | 可安装并能被任务表单消费的本地资源市场 |
| 视频号监控与解析后台 | 文件导入、文本粘贴和可配置命令行 ASR |
| 官方更新、公告与支付 | 保留界面语义并明确标注本地替代，不连接原站服务 |
| Storybound 1.16.1 客户端内置提示词 | 从公开分发客户端静态资源结构化提取，并按原赛道、画风和步骤接入本地流水线 |

这些替代覆盖可观察的产品工作流，但不宣称复制了不可获得的服务器代码、账户数据或商业授权。

官网落地页和桌面工作台彼此独立：

```text

  docs/research/app/      # 本次产品研究
```

## 4. 验收标准

- 三种图文模式在相同输入下能走到正确起始步骤。
- 任一步中断后重启应用，仍能检测已有产物并从正确位置恢复。
- 修改 Step 1/2/3 产物不会重跑更早步骤。
- 单条失败可修复，不覆盖成功图片或音频。
- 批量任务严格串行，当前条暂停/取消不会破坏后续队列。
- HTML 与 MV 在替换图片、字幕、音色或模板后可以只重打包。
- 浏览器不接触由本机凭据文件读取的密钥明文，日志和导出文件不泄露密钥。
- 对公网反向代理请求强制访问令牌；未配置令牌时拒绝非本机访问。
- 真实 MP4、剪映 ZIP、路由、响应式布局、构建和 API 安全检查全部通过。

详细结果见 [v1.16.1 QA 报告](../v1.16.1/QA_REPORT.md)。
