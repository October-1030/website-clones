# Storybound 桌面产品研究总览

当前实现对象：Storybound 1.16.1；1.13.1 动态研究资料保留为历史行为证据。

结论：Storybound 不是“落地页 + 一个生成按钮”，而是一套本地优先的桌面视频生产工作台。当前版本包含三类主创作入口、三种图文执行模式、可断点编辑的任务流水线、批量队列、模板与素材资产，以及若干选品和对标辅助模块。

## 已确认的产品边界

- 三类主创作入口：图文任务、HTML 动画视频、音乐 MV。
- 图文任务三种执行模式：全自动、半自动、直接出片。
- 图文任务固定 7 步：预审、改写、分句、提示词、生图、配音、剪映草稿。
- 任务可以暂停、确认、修改中间产物、修复失败项、从任意可复用步骤续跑。
- 原客户端证据显示其核心数据保存在本机数据库和任务目录；独立复刻使用每任务 JSON 目录、事件日志和本地资源目录。
- 原桌面端由 Tauri + React 构成；独立复刻使用 React + 本地 Node 服务完成音频处理、浏览器渲染、视频合成和剪映草稿打包。

## 研究原则

实现使用独立代码和用户自有的第三方 API 凭据，不复用原应用的授权机制或私有服务凭据。经用户明确要求，Storybound 1.16.1 客户端包中随前端分发的提示词模板已结构化提取，并按原赛道、画风和步骤映射接入本地流水线。
