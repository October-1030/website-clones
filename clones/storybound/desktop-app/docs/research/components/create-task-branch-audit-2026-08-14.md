# Storybound 全分支审计记录（2026-08-14）

## 范围

- 原版证据：Storybound 1.17.0 桌面包、`original-prompt-library.json`、公开产品页。
- 本地链路：创建表单 → 任务落盘/恢复 → 七步流水线 → 图片/TTS/素材 provider → 剪映草稿/媒体工作台。
- 枚举：8 个赛道、13 套画风、3 种运行模式、4 种暂停策略、3 种素材来源、4 个图片 provider、4 种配音时间线、6 套封面模板、19 个页面入口。
- 验收原则：选项必须同时满足“可见、可保存、可恢复、有运行消费端、有产物表现”，只有按钮不算完成。

## 逐分支结论

1. **8 个赛道**：人物故事、健康图书、传统文化、绘本故事、电商带货、心灵鸡汤、民间故事、通用故事均有独立默认模板、画风和图片策略。
2. **参考图**：人物参考、产品/器物参考和无固定参考三类已隔离；任务换赛道或换参考图会清除旧身份，不再继承上一人物。
3. **图片提示词**：于右任/李香兰等人物故事专用规则不再污染绘本、民间故事、产品、鸡汤或通用赛道。
4. **产品参考**：MiniMax `image-01` 只在人物参考路径发送 `subject_reference`；产品参考在 UI 中明确要求切换到支持器物参考的即梦路径。
5. **运行模式**：自动、半自动、直接使用均能决定真实起始步骤；直接模式的机械分句不再错误要求 LLM 密钥。
6. **暂停策略**：不停、关键节点、每步、自定义均进入实际暂停判断，不是仅存 UI。
7. **素材来源**：AI、网络素材、本地素材分别进入生成、Wikimedia 检索、本地匹配；网络/本地模式隐藏无效的画图选项。
8. **画风**：13 套原版画风和自定义画风均可保存；自定义 prompt/negative prompt 随任务恢复并传到所有图片 provider。
9. **封面**：关闭、带标题、留白不带字、本地上传及第二封面均有真实消费端；6 套原版模板统一由本地合成器精确排中文标题，避免 AI 乱码。
10. **配音**：逐镜 TTS、连续旁白、外部音频、播客 A/B 均写入真实时间线；BGM 预混为全片等长单轨。
11. **草稿**：字幕、音频、画面按真实音频时长对齐；发布封面保存为独立 3:4 文件，并以零秒单帧代理进入 9:16 时间线。
12. **媒体依赖**：Windows 会通过 `where.exe` 自动发现 Winget 安装的 FFmpeg/FFprobe，避免页面显示可用但渲染失败。
13. **页面入口**：17 个固定页面加任务详情、批次摘要两个动态入口均实际挂载并完成浏览器加载检查。
14. **密钥边界**：本轮差异未包含 MiniMax/API 实际密钥；本地 `key.txt` 保持 Git 忽略。

## 本轮修复

- 修复非人物赛道误套民国人物/于右任提示词。
- 修复直接模式无 LLM 时无法执行机械分句。
- 修复自定义画风只显示、不落盘或不传 provider。
- 修复 MiniMax 产品参考被错误当成人脸参考。
- 修复任务切换后沿用上一人物参考图。
- 修复非 MiniMax 封面未走精确中文排字。
- 修复 6 套封面模板 ID 与合成器分支不一致。

- 移除未消费的 `bgmSync` 表单伪分支和三处 lint 问题。
