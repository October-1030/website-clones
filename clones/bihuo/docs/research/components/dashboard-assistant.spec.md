# GEO 助理侧栏

参考：original-dashboard-assistant.png，已登录原站实际打开状态。

原站右侧约320px面板，标题栏60px，白/浅蓝背景，下载的机器人图片，当前页面说明；公司与GEO项目选择器、三条快捷问题、确认提示、消息输入和发送按钮。空态文案从DOM原样提取。完整页面入口、对话历史和不同停靠模式未纳入本地范围。

本地用320px右侧flex列；1024px以下覆盖主页面，宽度不超过100vw。可以展开/折叠、选择快捷问题、输入文字。2026-08-31 按用户要求将演示回复替换为真实 MiniMax 文本对话，由服务端 `POST /api/chat` 转发到官方接口。浏览器只发送文本，不接触模型密钥。标题显示配置模型，底部明确提示消息将发送至 MiniMax。

Enter发送、Shift+Enter换行；IME composition期间Enter不发送。等待时显示生成状态及停止按钮，防止重复提交；失败时显示安全错误并恢复输入。折叠保留当前内存对话，刷新或离开仪表盘清空。本项目不将聊天写入数据库、日志或本地存储。每次发送最多携带13条、16000字符的最近上下文，单条用户消息最多4000字符。

快速上手按钮打开教程。本机公司/GEO 项目可在助手顶部选择，但资料不会自动发送给模型；真实收录查询、文章发布仍未接入后台。模型系统提示与界面说明均明确这一范围。快捷提问可以说明检查方法，但不会伪造查询操作。消息以纯文本渲染，不执行模型返回的HTML。

资源：geo-agent-CtRbLfrG.png、DashIcon。详情见dashboard.css中geo-assistant和assistant-*规则。工具列和本地声明为功能范围适配。
