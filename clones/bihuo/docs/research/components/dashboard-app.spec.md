# 仪表盘框架、流程、教程与工具

来源：已登录原站 2026-08-31，Chrome 1440×1000 / 390×844；DOM、原始 CSS 和截图存于 research 与 design-references。

- 框架：左栏148px，顶栏60px；主滚动区 padding-top24px，卡片 gap24px，内容 min-width900 / max-width1760。800px以下左栏改抽屉，主内容宽度100%。
- 导航：品牌行60px，根菜单13px、组菜单12px；4根入口和7个可折叠组。原站 accordion，点击组关闭其他组。
- 顶栏：公司选择、刷新、搜索、全屏、通知、公告、语言、设置和头像；原始SVG图标已抽取。公告为空。
- 流程卡：padding28px，标题18px/28px，四组准备/内容/发布/收录，各3/3/3/1节点，组间24px和虚线。图标52px方块、8px圆角、主色8%底；标题14px，编号12px等宽。1200px以下分两排。原站流程按钮跳至相关业务页。
- 教程：全屏蓝黑径向渐变/模糊遮罩，max-width1000px舞台，276px机器人侧栏，右面板22px圆角、padding28px32px24px，四步切换和总结；机器人使用下载原图。
- 工具：Windows1.8.4、Mac1.8.3、插件1.1.6.4；右侧帮助文档。图标40px，标题15px，版本12px。
- 助手：右侧320px面板，机器人标题、本机公司与项目选择、三条快捷问题、输入框、发送；文本由服务端 MiniMax-M3 接口回复，不会执行原站发布或收录操作。

范围：目标仪表盘及公开登录/注册页已按原站对照；公司和 GEO 项目为本机工作区；其余侧栏业务入口使用明确标识的简化本机记录页，不冒充真实业务后台。工具安装包不伪造下载地址；登录/发布/付费不提交原站。完整差异见 `../FUNCTIONAL_AUDIT.md`。
