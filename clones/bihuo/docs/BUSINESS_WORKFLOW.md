# 本机 GEO 业务工作流

## 已可运行

数据保存在浏览器 `localStorage`，MiniMax 请求由本机服务端代理。已完成的链路：

1. 在“公司管理”创建公司和 GEO 项目。
2. 在“知识库”上传 TXT、Markdown、CSV、JSON，或直接粘贴知识正文。
3. 在“AI 拓展问题”选择公司/项目并调用 MiniMax-M3 生成搜索问题。
4. 在“提示词管理”保存写作规范。
5. 在“AI 文章创作”选择问题和提示词，用 MiniMax-M3 生成文章。
6. 把文章加入本机发布队列。
7. 保存人工核验或外部采集器返回的收录证据。
8. 使用本机统计和记录生成诊断报告、监测报告。
9. 仪表盘自动汇总问题、文章、收录检查和自有文章引用；收录分析按平台显示本机证据数量。

端到端验收数据：1 份知识资料、5 个 M3 搜索问题、1 篇 M3 文章、1 个发布任务、1 条收录记录和 1 份 M3 诊断报告；刷新后仍可读取。

## 接入生产服务所需配置

| 功能 | 必须提供的服务或凭证 | 当前行为 |
| --- | --- | --- |
| 真实登录 | 用户数据库、密码哈希、会话密钥、邮件/手机号验证策略 | 只有本机表单演示 |
| 短信验证码 | 短信服务商账号、签名、模板 ID、API 密钥、发送限流 | 固定本机测试码，不发送短信 |
| PDF/Word/OCR | 文档解析器或 OCR 服务 | 当前支持纯文本格式 |
| 媒体授权 | 各平台开放应用、App ID/Secret、回调域名和审核通过的权限 | 只有配置/记录入口 |
| 自动投稿与发布 | 平台发布 API 或合规客户端、账号授权、失败重试和审计日志 | 只创建本机发布队列 |
| 自动收录查询 | 搜索/AI 平台 API、合规采集器或配套浏览器插件 | 只保存人工或外部证据 |
| 积分和订单 | 商品、价格、支付商户、签名密钥、Webhook、退款流程 | 只有本机记录页 |
| 客户端下载 | Windows/macOS 安装包、代码签名、版本清单、托管地址 | 只保留原站入口和版本文案 |

不要把真实平台密钥保存到业务记录或浏览器本地存储。接入时应只把密钥放在服务端环境变量或专用密钥管理服务中。
