# 必火 GEO 界面复刻

独立 Next.js 16 + React 19 + TypeScript + Tailwind CSS v4 项目。

## 运行

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:3026/#/dashboard 。`npm run check` 执行 ESLint、TypeScript 和生产构建。

## 已实现

- 原站仪表盘：数据总览、公司范围筛选、指标说明、10步工作流、8个平台收录分析、月度趋势、工具下载与帮助区。
- 10个流程步骤已恢复原站对应路由。公司管理包含公司与 GEO 项目的新增、编辑、删除、选择和本机持久化。
- 可运行的本机 GEO 内容闭环：上传或粘贴知识文本、MiniMax-M3 生成搜索问题、提示词管理、M3 文章生成、本机发布队列、人工收录证据、M3 诊断与监测报告。
- 问题、文章、收录检查和平台证据会自动汇总回仪表盘；业务数据跨页面保存，刷新后仍可读取。
- 折叠侧栏、功能搜索、公告与通知空态、语言选择菜单、账户菜单、全屏与刷新。
- 四阶段新手教程、原图机器人和可收起的 GEO 助手面板。
- GEO 助手已接入 MiniMax-M3，支持真实文本对话、多轮上下文和停止生成；服务端接口为 `POST /api/chat`。配置与调用示例见 [API 说明](docs/API.md)。
- 原站公开登录页 `#/auth/login` 与手机号注册页 `#/auth/register`、hash 导航。
- 原图背景、玻璃表单、三种语言、密码显示切换、表单校验。
- 桌面 1440px、平板 768px、手机 390px 布局。
- 所有表单均为本地交互演示，不连接真实登录或短信服务，不保存或上传输入的账号密码。测试短信验证码为 `123456`。

## 演示范围

参考 `https://geo.bihuogeo.com/#/dashboard`，于2026-08-31检查公开认证页及用户已登录后的真实仪表盘。当前参考账户数据为0，保留原站空状态和参考日期，没有虚构图表或业绩。

公司管理已按原站公开前端实现名称、简介、别名及 GEO 项目字段，并在当前浏览器本机保存。知识库支持 TXT、Markdown、CSV、JSON 和粘贴正文；问题、文章和报告生成会把本次所需的可见文本发送给 MiniMax-M3，并消耗对应账户的模型用量。本机发布队列不会向第三方平台发稿，收录页面只保存人工或外部采集器提供的证据。真实短信、媒体 OAuth、自动发布、联网收录、支付订单和客户端安装包需要相应服务商凭证或程序，接入条件见 [业务工作流说明](docs/BUSINESS_WORKFLOW.md)。工具入口不伪造安装包或下载地址。本项目不持久化登录数据或聊天内容；MiniMax 对已发送内容的处理以其服务政策为准。

服务默认仅监听 `127.0.0.1:3026`。密钥放在被 Git 忽略的 `.env.local`，不使用 `NEXT_PUBLIC_` 变量，不发给浏览器。此为个人本机使用接口，不能直接作为公网服务部署；对外开放前需要真实用户认证、配额管理和持久化限流。

`docs/research` 保存设计规范、交互观察、组件说明、原始CSS及验收记录；`docs/design-references` 保存原站和本地截图。`scripts/download-assets.mjs` 可重新下载公开背景、平台图标和助手图片；`scripts/extract-icons.mjs` 可从已保存的DOM图标生成React组件。

原站自定义品牌图标的OSS地址无法下载，采用同站favicon；其余使用的图片与SVG均已保存在本地。为让手机导航可用，左上角原站悬浮图标在窄屏用作菜单入口。教程总结和业务入口说明为本地辅助文案。
