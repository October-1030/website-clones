# Creative toolbox

Observed source navigation: 创意 → 创作工具箱 → 黄金开篇生成器.
The source uses a scrollable card grid with 13 novel tools, then advanced tools.
Each novel card's displayed name/description was captured in the browser. No art assets.
Local extension reproduces these 13 visible novel tool names/descriptions using the
existing surface, border and primary tokens. Three columns on desktop, two below
1100px, one below 768px. Source title and introductory sentence are retained.

Golden-opening card opens the local generator. Other tools carry a visible 原站 label
and link out; they do not pretend to be working local generators. Sidebar and mobile
navigation highlight 创意 when selected. The library remains reachable through 作品.
